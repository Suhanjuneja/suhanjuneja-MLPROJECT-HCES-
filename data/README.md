# Local data folder (read before running)

The dataset is **not** in the GitHub project because it is a ~233 MiB archive of unit-level HCES 2022–23 records. Do **not** add it to a public repository.

Place the original file here, with exactly this name:

`data/CSV_data_HH_Cons_exp_22_23.zip`

Do not extract it. The analysis reads the two needed CSV levels directly from the ZIP.

Input SHA-256 observed in this study (for reference):

`093a51d337eb07eede7d6e2a00ec55790d926bacf869be2cf2825abd629444ae`

This hash verifies the ZIP bytes used in the provided run. The HCES survey questionnaires and official data documentation are published by MoSPI (https://mospi.gov.in/sites/default/files/publication_reports/HCES-22-23/AppendixA.pdf).

Only aggregated CSV tables and figures are committed to the project. Do not upload identifiers, household-level training rows or extracts from the dataset.
